# Формат CSV-шаблона проверки

Шаблон — обычная таблица CSV, которую удобно готовить в Excel, LibreOffice
или Google Sheets. Первая строка — заголовки колонок, каждая следующая строка —
одно поле проверки.

Пример: [`templates/sample.csv`](../templates/sample.csv).

---

## Колонки

| Колонка | Обязательна | Тип | Описание |
|---|---|---|---|
| `order` | нет | число | Порядок вывода поля. Если не указан или не число, используется позиция строки (шаг 10). |
| `name` | **да** | строка | Машинное имя поля. Должно быть непустым и **уникальным** — по нему хранятся ответы. |
| `label` | **да** | строка | Подпись, которую видит инженер. Если пуста, подставляется `name` с предупреждением. |
| `type` | **да** | перечисление | Тип поля, см. раздел «Типы полей». Неизвестное значение → `text` с предупреждением. |
| `group` | нет | строка | Группа = шаг формы. По умолчанию `Общие сведения`. Группы выводятся в порядке появления. |
| `required` | нет | флаг | `true`, `1`, `yes`, `да`, `истина`, `+`, `x`, `v` — обязательное поле. |
| `options` | для `dropdown` | список | Варианты выбора. Разделитель — первый найденный из `;`, `\|`, таб, `,`. |
| `placeholder` | нет | строка | Подсказка внутри пустого поля. |
| `description` | нет | строка | Пояснение, выводится под полем. |
| `unit` | нет | строка | Единица измерения: подставляется в подпись и в отчёт (`°C`, `МПа`, `лет`). |

Порядок колонок произвольный. Регистр заголовков не важен (`Name`, `NAME`, `name`
эквивалентны), пробелы и дефисы в заголовках заменяются на `_`.
Неизвестные колонки игнорируются и попадают в предупреждения.

---

## Типы полей

| `type` | Что показывает | Что сохраняется в JSON |
|---|---|---|
| `text` | Однострочное поле | строка |
| `number` | Поле с числовой клавиатурой; проверяется, что введено число | строка (`"62,5"`) |
| `date` | Выбор даты в календаре; отображается `ДД.ММ.ГГГГ` | строка ISO `"2026-08-11"` |
| `time` | Выбор времени | строка `"14:30"` |
| `dropdown` | Список из `options` | выбранная строка |
| `checkbox` | Флажок | `true` / `false` |
| `textarea` | Многострочное поле | строка |

Неизвестный тип не прерывает загрузку: поле становится `text`, а пользователь
видит предупреждение на экране проверки шаблона.

---

## Группировка

Поля с одинаковым `group` образуют один шаг формы. Шаги идут в порядке первого
появления группы в файле (после сортировки по `order`). Для примера
`templates/sample.csv` получаются шаги:

1. Общие сведения — 3 поля
2. Паспортные данные — 3 поля
3. Результаты осмотра — 5 полей
4. Заключение — 1 поле

---

## Кодировка и разделители

* Поддерживаются `UTF-8` (с BOM и без), `cp1251`/`windows-1251`, а также другие
  однобайтовые кодировки через автоопределение.
* Разделитель определяется автоматически: `,`, `;`, таб или `|`. Приоритет отдаётся
  варианту, дающему больше колонок в строке заголовков, поэтому запятые внутри
  значений не ломают разбор `;`-файла.
* Пустые строки пропускаются.
* Если значений в строке меньше, чем колонок, недостающие считаются пустыми;
  если больше — лишние игнорируются с предупреждением.

---

## Ошибки и предупреждения

Разбор разделяет проблемы на два класса.

### Ошибка — шаблон не загружается

Пользователь видит список **всех** найденных проблем сразу, с номером строки
и колонкой:

| Ситуация | Сообщение |
|---|---|
| Нет файла | `Файл не найден: …` |
| Пустой файл | `Файл пуст.` |
| Нет колонок `name`, `label`, `type` | `В шаблоне нет обязательных колонок: «name».` |
| Пустое `name` | `строка 4, колонка «name»: не заполнено машинное имя поля` |
| Дубликат `name` | `строка 7, колонка «name»: поле «model» уже описано в строке 5` |
| `dropdown` без `options` | `строка 9, колонка «options»: для поля «state» типа «список» не заданы варианты` |
| Ни одного поля | `В файле «…» не найдено ни одного поля проверки.` |

### Предупреждение — шаблон загружается

Предупреждения видны на экране проверки шаблона и не мешают работе:

* неизвестный `type` → поле становится `text`;
* пустой или нечисловой `order` → используется позиция строки;
* пустая подпись `label` → подставляется `name`;
* неизвестные колонки → игнорируются;
* значений в строке больше, чем колонок.

## Результат: файл проверки

Результаты сохраняются в `reports/inspections/<дата>_<шаблон>_<id>.json`.
Файл самодостаточен: содержит снимок полей шаблона (`template.fields`), поэтому
продолжение проверки и формирование отчёта не требуют исходного CSV.

```json
{
  "format_version": 2,
  "inspection_id": "befba306aebe47b6bcadcf0f0e552d38",
  "object_name": "Насос Н-12",
  "inspector": "Иванов И.И.",
  "started_at": "2026-08-11T07:17:07.206313+00:00",
  "finished_at": "2026-08-11T07:41:12.918005+00:00",
  "template": {
    "name": "sample",
    "version": "1.0",
    "warnings": [],
    "fields": [
      {
        "order": 80,
        "name": "temperature",
        "label": "Температура",
        "type": "number",
        "group": "Результаты осмотра",
        "required": false,
        "options": [],
        "placeholder": "Введите температуру",
        "description": "Измерьте температуру корпуса",
        "unit": "°C"
      }
    ]
  },
  "items": [
    { "field": "temperature", "value": "62,5", "comment": "", "is_checked": true }
  ]
}
```

Файлы формата `format_version: 1` (первая версия приложения) при загрузке
конвертируются в текущий формат: поля восстанавливаются по именам, группировка
теряется, о чём добавляется предупреждение.
